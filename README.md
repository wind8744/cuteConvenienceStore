# cuteConvenienceStore

스타듀밸리풍 픽셀 아트의 **편의점 타이쿤**입니다. 작은 마을 한가운데 편의점을 운영하면서 진열대를 채우고, 손님을 계산해 주고, 번 돈으로 가게를 키웁니다. 그림·효과음·배경 음악을 전부 코드로 만들어서 아트·사운드 에셋이 없습니다. Unity 6, C#.

## 요구 사항

- **Unity 6000.0.84f1** (Unity 6 LTS) — [Unity Hub](https://unity.com/download)로 설치
- Git

## 시작하기

1. 저장소를 클론하고 Unity Hub에서 **Add** → 폴더를 선택해 엽니다.
2. 메뉴 **Tools > Project > Play ConvenienceStore** 를 누르면 `Assets/Scenes/ConvenienceStore.unity` 를 열고 바로 실행됩니다.

## 조작

- 방향키 / WASD = 이동
- Space = 계산대 뒤에서 계산, 진열대 옆에서 상품 채우기, 마을 사람에게 말 걸기·부탁한 물건 건네기, 연못가에서 낚시
- F = 진열대에서 상품 하나 집기 (같은 상품 3개까지) · G = 손에 든 상품 제자리에 돌려놓기
- E = 마을의 집 문 앞에서 전단지 넣기
- P = 상품 관리 (어떤 상품을 들여오고 팔지 고르기)
- Q = 진열대 옆에서 그 상품의 가격대 바꾸기 (보통 → 비싸게 → 싸게)
- Tab = 마을 수첩 (단골 이름·좋아하는 상품·호감도)
- 정산 화면: 1~4 = 업그레이드 구매, Space = 다음 날, Backspace = 새 게임
- M = 배경 음악 켜고 끄기

## 규칙

- **영업**: 08:00~22:00 (실제 약 150초). 점심(12시)과 저녁(18~20시)에 손님이 몰립니다.
- **손님**: 절반쯤은 마을 집에 사는 단골이고 나머지는 마을 밖에서 길을 따라 옵니다. 편의점까지 걸어와서 원하는 상품의 진열대에서 1~3개를 집어 계산 줄에 섭니다. 계산하면 판매가만큼 벌고 평판이 오릅니다. 볼일이 끝나면 집으로 돌아갑니다.
- **놓친 손님**: 진열대가 비어 있거나(느낌표 말풍선) 줄에서 너무 오래 기다리면 화내며 나가고 평판이 떨어집니다. 평판(하트)이 높을수록 손님이 자주 옵니다.
- **진열**: 상품을 채울 때 매입가(보통 판매가의 절반)를 냅니다.
- **가격대**: 상품마다 싸게(-20%)·보통·비싸게(+30%)를 고릅니다. 싸게 팔면 손님이 그 상품을 더 찾고 평판이 빨리 오르며, 비싸게 팔면 덜 찾고 평판이 천천히 오릅니다. 진열대 오른쪽 위 딱지가 파랑이면 싸게, 금색이면 비싸게입니다.
- **상품 관리(P)**: 12종 상품 가운데 무엇을 팔지 직접 고릅니다. 안 들여온 상품은 Enter 로 값을 치르고 들여오고(순서 상관없음, 첫 물량 가득), 들여온 상품은 Space 로 판매/보류를 바꿉니다. 보류 중인 상품은 손님이 찾지 않고 진열대가 푸르스름하게 보입니다.
- **마을 사람과 친해지기**: 마을 사람은 집에 있을 때 집 앞을 어슬렁거립니다(머리 위 하트). 다가가 Space 로 말을 걸면 하루 한 번 호감도가 1 오르고, 가게에서 계산해 줘도 1, 부탁을 들어주면 2 오릅니다.
- **부탁(퀘스트)**: 매일 마을 사람 한두 명이 상품을 부탁합니다(상단 바 아래에 표시). 진열대에서 F 로 상품을 집어 들고(최대 3개) 그 사람에게 가서 Space 로 건네면 보상(물건값 + 3,000원 + 날짜×1,000원)과 호감도 2를 받습니다. 부탁은 그날 안에만 유효합니다.
- **단골**: 집 여섯 채에 이름과 좋아하는 상품이 있는 단골이 삽니다(머리 위 하트). 계산해 줄 때마다 호감도가 1씩 올라 최대 10이 되고, 친할수록 팁이 후해지며 호감도 5와 10에 선물을 줍니다. 좋아하는 상품을 들여놓으면 주로 그것을 사러 옵니다.
- **인내심 막대와 팁**: 줄 선 손님 머리 위 막대가 초록일 때 주인이 직접 계산하면 물건값의 15%를 팁으로 받습니다(알바생이 계산하면 팁 없음). 막대는 노랑·빨강으로 바뀌다가 다 닳으면 손님이 나갑니다.
- **연속 응대**: 손님을 놓치지 않고 5명씩 연속으로 응대할 때마다 평판이 더 오릅니다.
- **특별한 손님**
  - 바쁜 손님(번개): 걸음이 빠르고 금방 지치지만 제때 계산하면 팁이 2배입니다.
  - VIP(왕관): 평판이 하트 3개쯤 되면 가끔 찾아와 4개를 사고 팁을 3배로 줍니다.
  - 진상 손님(빨간 화): 둘째 날부터 옵니다. 줄 맨 앞으로 새치기하고, 줄 선 다른 손님들을 두 배로 빨리 지치게 하고, 값을 깎아(싸게 가격) 사며, 팁도 평판도 없습니다. 빨리 보내는 게 상책입니다.
  - 착한 손님(별): 느긋하게 기다리고, 기다렸더라도 팁을 주고, 평판을 두 배로 올려 줍니다.
- **오늘의 목표**: 매일 응대할 손님 수 목표가 있고(1일차 8명, 매일 2명씩 늘어 최대 24명) 채우면 정산 때 보너스를 받습니다.
- **그날의 사정**: 둘째 날부터 비 오는 날(손님이 줄고 컵라면 인기), 소풍날(삼각김밥·과자·도시락), 무더위(아이스크림·바나나우유), 월급날(손님이 몰리고 하나씩 더 구매)이 무작위로 찾아옵니다.
- **마을**: 가게 문 밖(아래쪽)으로 걸어 나가면 마을로 나옵니다. 가운데에 편의점이 있고 집 여섯 채, 연못, 나무가 길로 이어져 있습니다. 편의점 입구에서 위쪽으로 걸으면 다시 가게 안으로 들어갑니다. 마을에 나가 있는 동안에도 영업 시간은 흐릅니다. 밤에는 가로등에 불이 들어옵니다.
- **낚시**: 마을 연못가에 서서 Space 를 누르면 낚시를 시작합니다. 입질(느낌표)이 오면 Space, 그다음 움직이는 표시가 초록 칸에 있을 때 다시 Space 를 누르면 물고기를 잡아 바로 돈이 됩니다(붕어 1,500원 ~ 금붕어 6,000원, 가끔 장화). 낚시하는 동안에도 가게 시간은 흐릅니다.
- **전단지**: 마을에서 집 문 앞에 서서 E 를 누르면 전단지를 넣습니다. 하루에 집마다 한 번, 그 집 단골이 집에 있으면 바로 3개를 사러 나옵니다.
- **정산과 업그레이드**: 마감 후 임대료(하루 5,000원, 매일 1,500원씩 인상)를 내고, 번 돈으로 진열대 확장·계산 알바(자동 계산)·진열 알바(빈 진열대를 알아서 채움)·전단지 홍보를 살 수 있습니다. 알바는 각각 일당이 나갑니다. 정산 후 잔고가 마이너스면 폐업입니다.
- **저장**: 하루를 시작할 때마다 자동 저장되고 다음에 켜면 그날부터 이어 합니다.

## 폴더 구조

```
Assets/
  Scenes/ConvenienceStore.unity 게임 씬 (카메라 + ConvenienceStoreGame). 나머지는 실행 중 코드가 만든다
  Scripts/ConvenienceStore/
    TileGrid.cs                 문자 배치도 타일 맵 공통 부분, 길찾기(BFS)
    StoreMap.cs                 가게 안 배치도, 진열대·계산대·줄 위치
    VillageMap.cs               마을 배치도 (집·편의점·길·연못·나무). DefaultLayout 문자열을 고치면 맵이 바뀐다
    StoreEconomy.cs             잔고·평판·매입/판매·가격대·단골·팁·목표·그날의 사정·업그레이드·하루 정산·저장 데이터
    ShelfStock.cs, Product.cs   진열대 재고, 상품 목록(매입가·판매가)
    PixelCanvas.cs, StoreArt.cs 코드로 그리는 픽셀 아트 (타일, 가구, 캐릭터, 아이콘)
    VillageArt.cs               마을 픽셀 아트 (바닥, 집, 편의점 외관, 나무, 가로등)
    StoreAudio.cs               코드로 만드는 8비트풍 효과음과 배경 음악
    CharacterView.cs            걷기 애니메이션, 깊이 정렬, 말풍선
    StoreOwner.cs, Customer.cs  플레이어(주인) 이동, 손님 행동
    VillageWalker.cs            마을 길을 걷는 사람
    ShelfView.cs                진열대 표시
    Stocker.cs                  진열 알바 (빈 진열대를 찾아가 채움)
    Fishing.cs                  연못 낚시 미니게임
    ResidentNpc.cs              집 앞을 어슬렁거리는 마을 사람
    ConvenienceStoreGame.cs     하루 진행·손님 등장·계산/진열·HUD (Inspector에서 하루 길이, 손님 인내심 등 조절)
  Tests/EditMode/               맵·경제·저장·아트·사운드 테스트 (Window > General > Test Runner)
  Editor/AutoPlay.cs            Tools > Project > Play ConvenienceStore 메뉴
```

## 컨벤션

- 클래스와 파일 이름은 PascalCase, 비공개 필드는 `_camelCase`.
- 씬과 에셋은 **Force Text** 직렬화를 사용합니다.
